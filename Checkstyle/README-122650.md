## 3. Limitações do Checkstyle
O Checkstyle assegura de forma rigorosa a conformidade sintática e estilística através de expressões regulares, garantindo consistência visual na base de código. Contudo, a ferramenta possui limitações semânticas evidentes: é incapaz de inferir se o nome atribuído descreve de forma fidedigna e clara o conceito que representa no domínio da aplicação, validando qualquer sequência de caracteres desde que respeite o padrão estrutural definido.
