## 4. Reflexão Crítica
A introdução do Qodana no pipeline de CI/CD permitiu detetar de forma automatizada ramificações excessivas no código antes da integração no ramo principal. Métodos com múltiplos caminhos de execução independentes aumentam o esforço de teste unitário e a probabilidade de introdução de defeitos. Um aspeto crítico observado relaciona-se com falsos positivos: estruturas como blocos `switch` extensos para mapeamento de valores simples inflacionam a complexidade ciclomática sem representarem necessariamente um mau desenho. O limiar de 8 revelou-se equilibrado para isolar métodos que realmente beneficiam de decomposição lógica.
